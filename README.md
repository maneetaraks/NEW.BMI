# 🌟 BMI Health Tracker & Calculator (โปรแกรมคำนวณดัชนีมวลกาย)

เว็บแอปพลิเคชันคำนวณค่าดัชนีมวลกาย (**Body Mass Index - BMI**) อัจฉริยะ ออกแบบด้วย UI ที่ทันสมัย ใช้งานง่าย รองรับทั้งบนคอมพิวเตอร์และมือถือ พร้อมฟังก์ชันวิเคราะห์สุขภาพรอบด้าน

🔗 **GitHub Repository:** [https://github.com/maneetaraks/NEW.BMI](https://github.com/maneetaraks/NEW.BMI)

---

## ✨ ฟีเจอร์เด่น (Key Features)

- 🧮 **คำนวณค่า BMI พร้อม Visual Gauge**:
  - แสดงผลค่า BMI แบบตัวเลขพร้อมเข็มมาตรวัดแบบโค้ง (Semicircle Animated Gauge)
  - แถบสีจำแนกสถานะร่างกายตามระดับมาตรฐาน
- 🇹🇭 **รองรับ 2 มาตรฐานการประเมิน**:
  - **เกณฑ์เอเชีย / ไทย (Asian-Pacific Criteria)**: อ้างอิงกรมอนามัย กระทรวงสาธารณสุข (18.5 - 22.9 คือเกณฑ์ปกติ)
  - **เกณฑ์สากล (WHO Criteria)**: อ้างอิงองค์การอนามัยโลก (18.5 - 24.9 คือเกณฑ์ปกติ)
- 🎯 **คำนวณช่วงน้ำหนักที่เหมาะสม (Ideal Weight Range)**:
  - คำนวณช่วงน้ำหนักที่ดีที่สุดตามความสูง
  - แจ้งเตือนน้ำหนักส่วนต่างที่ควรเพิ่มหรือลดเพื่อกลับสู่เกณฑ์สมส่วน
- ⚡ **คำนวณอัตราเผาผลาญพลังงาน (BMR & TDEE)**:
  - **BMR (Basal Metabolic Rate)**: พลังงานขั้นต่ำที่ร่างกายต้องการในแต่ละวัน (ใช้สูตร Mifflin-St Jeor)
  - **TDEE (Total Daily Energy Expenditure)**: พลังงานที่ใช้ต่อวันตามระดับกิจกรรมจริง (1.2 - 1.9)
- 💡 **คำแนะนำสุขภาพเฉพาะบุคคล (Personalized Advice)**:
  - คำแนะนำด้านโภชนาการ การออกกำลังกาย และความเสี่ยงต่อโรคเรื้อรังตามผลลัพธ์ของแต่ละบุคคล
- 🕒 **บันทึกประวัติการคำนวณ (History Tracking)**:
  - บันทึกประวัติการคำนวณ 10 ครั้งล่าสุดแบบอัตโนมัติผ่าน LocalStorage ในเบราว์เซอร์
- 🌓 **Dark Mode / Light Mode**: ปรับโหมดมืด-สว่างได้ตามความชอบ
- 🌐 **รองรับ 2 ภาษา**: สลับเปลี่ยนระหว่างภาษาไทย (TH) และภาษาอังกฤษ (EN) ได้ทันที
- 📱 **Fully Responsive**: รองรับทั้งจอมือถือ แท็บเล็ต และคอมพิวเตอร์

## 📐 สูตรการคำนวณที่ใช้ (Formulas)

### 1. ค่าดัชนีมวลกาย (BMI)
$$\text{BMI} = \frac{\text{น้ำหนัก (kg)}}{\text{ส่วนสูง (m)}^2}$$

### 2. เกณฑ์การแปลผล (Asian vs WHO)
| ระดับสถานะ | เกณฑ์เอเชีย/ไทย (kg/m²) | เกณฑ์สากล WHO (kg/m²) | ความเสี่ยงต่อโรค |
| :--- | :---: | :---: | :--- |
| **น้ำหนักน้อย / ผอม** | < 18.5 | < 18.5 | เสี่ยงต่อภาวะขาดสารอาหาร |
| **น้ำหนักปกติ / สมส่วน** | 18.5 – 22.9 | 18.5 – 24.9 | สุขภาพดี ความเสี่ยงต่ำสุด |
| **น้ำหนักเกิน / ท้วม** | 23.0 – 24.9 | 25.0 – 29.9 | เริ่มเสี่ยงต่อเบาหวาน/ความดัน |
| **อ้วนระดับ 1** | 25.0 – 29.9 | 30.0 – 34.9 | เสี่ยงสูงต่อโรคเรื้อรัง |
| **อ้วนระดับ 2 / อ้วนอันตราย** | ≥ 30.0 | ≥ 35.0 | เสี่ยงอันตรายสูงสุด |

### 3. พลังงานพื้นฐาน BMR (Mifflin-St Jeor Formula)
- **เพศชาย:** $\text{BMR} = (10 \times \text{น้ำหนัก kg}) + (6.25 \times \text{ส่วนสูง cm}) - (5 \times \text{อายุ}) + 5$
- **เพศหญิง:** $\text{BMR} = (10 \times \text{น้ำหนัก kg}) + (6.25 \times \text{ส่วนสูง cm}) - (5 \times \text{อายุ}) - 161$

## 🚀 วิธีการติดตั้งและรันใช้งาน (How to Run)

### วิธีที่ 1: เปิดใช้งานโดยตรงผ่านเบราว์เซอร์ (ง่ายที่สุด)
- ดับเบิลคลิกเปิดไฟล์ `index.html` บนเบราว์เซอร์ (Chrome, Edge, Firefox, Safari) เพื่อใช้งานได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเสริม

### วิธีที่ 2: รันผ่าน Node.js
1. ตรวจสอบว่าเครื่องมี **Node.js** (คำสั่ง `node -v`)
2. เปิด Terminal ในโฟลเดอร์โปรเจกต์
3. รันคำสั่ง:
   ```bash
   npm start
   ```
4. เปิดเบราว์เซอร์ไปที่: 👉 **http://localhost:3000**
